id-kecamatan-geo

Simplified Indonesian kecamatan (admin level 3) boundaries as GeoJSON, for map visualisation.

  • kecamatan.geojson - all 7,069 kecamatan (national view)
  • provinsi/<adm1_pcode>.geojson - one file per province, listed in index.json

Join on the adm3_pcode property.

Boundaries: Badan Pusat Statistik (BPS - Statistics Indonesia), via OCHA and the Humanitarian Data Exchange, licensed CC BY-IGO. Simplified and split by province. Build script and details: github.com/klikpeta-tech/id-kecamatan-geo.
